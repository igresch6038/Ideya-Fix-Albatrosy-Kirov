# Ideya-Fix-Albatrosy-Kirov


1) загрузить файлы с гитхаб
.
git clone https://github.com/igresch6038/idea-fix-albatrosy-kirov.git
cd idea-fix-albatrosy-kirov
.
2) отредактировать в .env строки
BOT_TOKEN=токен_твоего_бота_из_MAX
WEB_URL=http://ВАШ_IP:3000
.
где токен_твоего_бота_из_MAX это токен бота, а ВАШ_IP это аддрес строки IPv4-адрес из абзаца, в зависимости от способа подключения к сети интернет, команды ip config
.
3) в командной строке выполни команду docker compose up -d
.
проект активен!
