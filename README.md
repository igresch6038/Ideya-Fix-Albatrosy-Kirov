# Ideya-Fix-Albatrosy-Kirov

### 1) загрузить файлы с гитхаб
```txt
git clone https://github.com/igresch6038/Ideya-Fix-Albatrosy-Kirov.git
cd ./Ideya-Fix-Albatrosy-Kirov
```
### 1.1) в файле перечислены библиотеки используемые в проекте но устанавливать их не надо, они уже в докер образе
### 2) отредактировать в .env строки
```.env
BOT_TOKEN=токен_твоего_бота_из_MAX
WEB_URL=http://ВАШ_IP:3000
```
где токен_твоего_бота_из_MAX это токен бота, а ВАШ_IP это аддрес строки IPv4-адрес из абзаца, в зависимости от способа подключения к сети интернет, команды ```ipconfig```
### 3) в командной строке выполни команду 
```bash
docker compose up -d
```
проект активен!

### Инструкция по использованию
1. строение логина ```xxyyyy``` где xx - номер региона, yyyy - номер школы пример:
```txt
439999 = Киров 9999 школа
```
2. строение пароля ученика ```aabbcc``` где aa - номер класса, bb - номер буквы класса в алфавите, cc - номер ученика в классе по очереди добавления пример:
``` txt
110204 = 11 класс, буква класса Б, был добавлен четвёртым
```
3. есть 3 вида аккаунтов:
```txt
Администратор: логин = 6038; пароль = admin,

старший учитель и классный руководитель: логин = номер школы; пароль = 000001 (у каждого следующего добавленного педагога в школе номер прибавляется наа единицу),

ученик: логин = номер школы; пароль = по принципу строения пароля ученика
```
***4. на сайт может входить только ученик, учителя (как слассный руководитель так и старший учитель) и админ входить туда не могут!***
